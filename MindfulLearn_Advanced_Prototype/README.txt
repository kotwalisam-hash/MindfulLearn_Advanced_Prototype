MINDFULLEARN — ADVANCED MOBILE PROTOTYPE
Project title: Non-Addictive Gamified Learning
Domain: Ethics and Education

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted MindfulLearn_Advanced_Prototype folder in VS Code.
3. Open index.html.
4. Right-click index.html and choose "Open with Live Server" (recommended).
   If Live Server is not installed, install the VS Code extension named "Live Server".
5. For phone preview, connect laptop and phone to the same Wi-Fi and use Live Server's network URL, or upload the folder to a static hosting service.

PROTOTYPE SCREENS
- Overview dashboard and emotional check-in
- Learning library with search and filters
- Focused lesson screen with pause and completion actions
- Progress dashboard and healthy-use indicators
- Ethical rewards and milestones
- Profile and gentle-support settings

INTERACTIONS
- Navigate using sidebar or bottom mobile navigation.
- Select a mood check-in.
- Search and filter learning cards.
- Open a course, pause a session, or mark a lesson complete.
- Open help, save settings, and see toast feedback.

DESIGN / ETHICAL PRINCIPLES
- No daily streak counter or streak-loss penalty.
- No countdowns, loot boxes, expiring rewards or forced return prompts.
- Progress is framed as personal reflection, not student ranking.
- Healthy use is represented through goals, breaks and reflection, not raw screen time.
- Students control reminders and privacy preferences.

NOTE
This is a front-end interactive prototype using sample data. Login, cloud database, real course content and persistent account storage are not connected. It is suitable for demonstrating the proposed UX and interactions; backend integration can be added as a later development phase.
